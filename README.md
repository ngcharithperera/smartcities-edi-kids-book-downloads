# Design Ideas for Inclusive Smart Cities

Public downloads for a free illustrated book that helps children, families, teachers, planners, and community groups explore more accessible, fair, safe, welcoming, and climate-ready cities.

The final public edition contains **243 illustrated stories**, identified as **D001–D243**. Each storyboard is followed by a Think & Talk page with a big idea, discussion questions, and a design activity.

## Read and download

- [Book website](https://ngcharithperera.github.io/smartcities-edi-kids-book/)
- [Final public release (v2.0.0)](https://github.com/ngcharithperera/smartcities-edi-kids-book-downloads/releases/tag/v2.0.0)
- [Searchable text companion](https://ngcharithperera.github.io/smartcities-edi-kids-book/book-text.html)

The release provides the same 516-page book in three PDF sizes:

| Option | Approximate size | Best for |
|---|---:|---|
| Lowest quality | 67.5 MB | Phones, slower connections, and quick sharing |
| Standard quality | 186 MB | Everyday reading, classroom display, and printing |
| Highest quality | 1.21 GB | Archiving and high-quality production |

The release also includes HTML and Markdown text companions, a machine-readable story catalogue, checksums, and a release manifest.

## Topics

Accessibility, inclusive mobility, public space, safety and care, ageing, children and young people, sensory inclusion, digital inclusion, housing and services, culture and belonging, fair work, climate resilience, shared decisions, and evaluation.
